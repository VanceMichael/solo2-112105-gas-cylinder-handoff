# 净化气瓶批次凭据与领用额度

资料联调站以本地合成资料模拟分别维护的业务来源。用 Node.js 22.23.4 启动，支持在同一进程中切换来源发布。启动后地址默认是 `http://127.0.0.1:4178`，可用环境变量 `PORT` 修改。

```sh
npm run origin
npm test
```

`npm run origin` 为独立的来源服务。`npm test` 另起临时端口验证资料站，不需要预先启动来源进程。资料领取仅需 Node.js 标准库。

联调站的 `GET /_desk/releases` 返回发布名与当前档。值台可向 `/_desk/releases/发布名` 发送 POST 切换资料，发布名按 UTF-8 进行 URL 编码。可选档位为首发、补报、更正。切换后各来源从当前档的内容响应，业务数据以原接口的版本字段与时间为准。联调档位名称仅用于控制资料站。

## 来源协议

交接站给 `/stations/transfers`，净化中心给 `/plant/ledger`。两者均用 `rows` 和下一页 `next`，接下来的链接带 `cursor`。来源可能重发同一 `id`。`receivedBy` 是交接站已确认的接收工序号。净化账上的 `lot` 是分合的实物批，`fill` 是单次充装的业务号。工序更正里的 `moves` 从被更正的充装中迁出所列瓶和克数，其余瓶及原工艺损耗留在原工序，迁出部分的来源仍是 `inputLot`。
从 `/lab/fills/{fill}` 查看报告和撤回清单。报告条目给原件地址、摘要、适用瓶和结论，撤回条目标识具体报告和适用范围。`requests.json` 是检修班给仓库的领用需求格式，每个 `ref` 是独立申请。该文件中的数量为克。

`sources/exchange.json` 保存联调站的来源记录和原件载荷，`sources/requests.json` 保存业务席可用的请求材料。材料中的单位、标识、组织及记录内容均为合成。
